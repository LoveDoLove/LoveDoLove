# LoveDoLove — AGENTS.md

GitHub profile monorepo: profile README + daily automation, plus a static Astro portfolio site in `portfolio-website/`. No backend, no database, no test suite. Docs are English; the fork-sync architecture doc body is zh-TW.

## Portfolio site
- Astro ^7.2.1, pnpm 11.9.0, wrangler ^4.121.0 (dev-dep). Single page `src/pages/index.astro`, 9 components, no client-side JS.
- **Deploy is manual only** (no CI): from `portfolio-website/` run `pnpm run deploy` (= `astro build && wrangler deploy`).
- Cloudflare Workers static assets, custom domain `portfolio.lovedolove.qzz.io` (`wrangler.jsonc`, `astro.config.mjs`).
- README/portfolio stat widgets call self-hosted API forks: `personal-trophy.vercel.app`, `github-stats-extended.vercel.app`.

## Automation (`.github/workflows/`)
| Workflow | Trigger | Logic source |
|---|---|---|
| `github-forks-sync.yml` | daily 00:00 UTC + manual (account override) | reusable workflow in `LoveDoLove/Github-Forks-Sync-Manager`; needs var `FORK_SYNC_ACCOUNTS` + secret `GH_PAT` |
| `sync-top-starred-projects.yml` | daily 00:00 UTC + manual | reusable workflow in `Github-Forks-Sync-Manager`; syncs top-starred projects into README |
| `generate-3d-contribution-graph.yml` | daily 00:00 UTC + manual | `yoshi389111/github-profile-3d-contrib`; regenerates `profile-3d-contrib/` and auto-commits |
| `generate-snake.yml` | daily 00:00 UTC + manual | `Platane/snk/svg-only@v3`; regenerates `profile-snake/` and auto-commits |
| `cleanup-failed-runs.yml`, `cleanup-all-runs.yml` | manual only | scripts curl'd at runtime from `LoveDoLove/Github-Action-Cleaner` |

Automation logic lives in those external repos. This repo only wires triggers and credentials — fix logic there, not here.

## Rules
- **Never hand-edit `profile-3d-contrib/` or `profile-snake/`** — fully generated by `generate-3d-contribution-graph.yml` / `generate-snake.yml`.
- `.gitignore` intentionally hides `*instructions.md`, `Resume*`, `*Resume*` — deliberate privacy convention; do not commit such files.
- Expect automated daily commits: README sync + `profile-3d-contrib/` + `profile-snake/` regeneration.
